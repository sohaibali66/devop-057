# Completing and exporting the report PDF

1. Complete [REPORT_TEMPLATE.md](./REPORT_TEMPLATE.md) with the actual GitHub, Docker Hub, successful run, and failed run URLs. Add real webhook observations and describe a problem only if you personally encountered it.
2. Replace all screenshot placeholders with evidence from your own repository, Docker Hub, local browser, and Actions runs. Do not insert mock or fabricated evidence.
3. Move the completed content into Word, Google Docs, or another editor that can export PDF. Use a compact readable layout, modest margins, and appropriately sized screenshots.
4. Keep all four submission links (GitHub repository, Docker Hub repository, successful Actions run, failed Actions run) visible on the first page. Continue with the project overview, evidence, webhook results, and real problem/solution section.
5. Export or download as PDF. Use a filename such as `Assignment-2-Sohaib-Ali-FA23-BAI-057.pdf`.
6. Open the exported PDF and verify that the first page visibly contains all four working links, screenshots are legible, no placeholders remain, and the rest of the report follows the first page.

This template intentionally does not generate a PDF automatically: actual submission links, webhook observations, problem details, and screenshots must be collected and checked by the student first.
